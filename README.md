# Astrologer CRM

A Customer Relationship Management (CRM) system designed for astrologers to manage clients, consultations, appointments, payments, and follow-ups efficiently.

## Features

### Authentication
- Secure Login & Registration
- JWT Authentication
- Role-Based Access Control (Admin, Astrologer)

### Client Management
- Add/Edit/Delete Clients
- View Client Profiles
- Search and Filter Clients
- Track Consultation History

### Appointment Management
- Schedule Appointments
- Reschedule or Cancel Appointments
- Appointment Status Tracking
- Calendar View

### Consultation Management
- Record Consultation Details
- Maintain Consultation Notes
- Upload Supporting Documents

### Payment Tracking
- Record Payments
- Payment History
- Revenue Dashboard

### Dashboard
- Total Clients
- Upcoming Appointments
- Completed Consultations
- Revenue Summary

## Tech Stack

### Frontend

### Backend
